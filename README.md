# Essais

A collection of essays, organized by essayist. Designed as a submodule for [krisyotam.com](https://krisyotam.com), mounted at `/essais`.

## Structure

- `/` — essayist index
- `/essayist-name/` — essay index for that essayist
- `/essayist-name/essay-title/` — the essay itself

All pages are plain, unstyled HTML.
